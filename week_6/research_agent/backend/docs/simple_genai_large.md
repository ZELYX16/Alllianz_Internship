# The Big Book of AI

## What is Generative AI?
Generative AI is a type of computer program.
It can make new text.
It can make new images.
It can make new code.
It reads a prompt from a human.
Then it guesses the next words.
It is like a smart autocomplete tool.

## What are the limits of Generative AI?
Generative AI has a few limits.
First, it has a knowledge cutoff date.
It does not know what happened yesterday.
Second, it can hallucinate.
This means it makes up false facts.
Third, it cannot take actions.
It cannot search the live internet on its own.
It cannot delete files on a computer.
It cannot send emails to people.

## What is Agentic AI?
Agentic AI is different from basic Generative AI.
Agentic AI uses an AI model as a brain.
But it also gives the AI model tools to use.
These tools are like hands for the AI.
An agent can use a tool to search the internet.
An agent can use a tool to calculate math.
An agent can use a tool to read local files.

## How does an Agent think?
An agent uses a thinking loop.
This loop is called the ReAct framework.
ReAct stands for Reasoning and Acting.
First, the agent makes a Thought about the goal.
Second, the agent takes an Action by using a tool.
Third, the agent looks at the Observation from the tool.
It repeats this loop until it finds the final answer.
